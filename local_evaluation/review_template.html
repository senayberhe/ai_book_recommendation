How to rate fairly

Judge only the evidence in the title, authors and description. Topic relevance: 0 = unrelated or contradicts an explicit request; 1 = partially meets the request; 2 = strong match. Respect audience and category constraints.

Mood fit is separate: 0 = unsupported or conflicting; 1 = plausible/weak evidence; 2 = clear evidence. If the description is insufficient for a fair judgment, leave the item unrated and note it for discussion. Do not guess the book's contents.

Rate every candidate in a query before moving on. There is no preset correct answer and no default selected grade. Work is saved in this browser for this run. Export a JSON backup when finished; the browser cannot update project files directly. This page sends no network requests.
